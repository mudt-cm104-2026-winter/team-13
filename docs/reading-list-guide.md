# Student Reading List Guide

## Overview
This web application lets students save, manage, and view a shared reading list with book titles and authors.

## Features
- **Add Entries:** Enter a book **Title** and **Author** in the form and submit to save it to the list.
- **View & Count:** Displays all saved books in a table along with the total reading list count.
- **Delete & Manage:** Allows users to remove finished or unwanted books using the delete button and organize entries.
